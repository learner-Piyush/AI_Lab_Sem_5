## About This Repository

This repository contains the Python-based laboratory assignments completed as part of the **Artificial Intelligence Laboratory** course in Semester V at **Haldia Institute of Technology**.

The work is organized into Jupyter Notebooks, with each notebook covering a set of practical exercises. Topics include Python programming, data structures, search algorithms, NumPy, Pandas, and data visualization.

## Repository Contents

| File / Folder | Description |
|---|---|
| `Assignment1.ipynb` | Python lists, dictionaries, sets, filtering, and basic collection operations |
| `Assignment2.ipynb` | List indexing, sorting, membership, repeated elements, number checks, and nested loops |
| `Assignment3.ipynb` | Breadth-First Search (BFS), Depth-First Search (DFS), calendar, and a simple chatbot |
| `Assignment4.ipynb` | Python functions, calculator, recursion, scope, generators, lambda, and filter |
| `Assignment5.ipynb` | Pandas MultiIndex operations and adding DataFrame columns |
| `Assignment6.ipynb` | Pandas DataFrame operations: delete, rename, reorder, merge, insert, and conversion |
| `Assignment7.ipynb` | NumPy arrays and Matplotlib visualizations |
| `Assignment8.ipynb` | NumPy arithmetic, reshaping, appending, sorting, and advanced Matplotlib plots |
| `Assignment9.ipynb` | Greedy Best-First Search, A* Search, and Hill Climbing |
| `Images/` | Output images/screenshots associated with Assignments 7 and 8 |
| `environment.yml` | Conda environment export |
| `.gitignore` | Files and folders excluded from Git tracking |

- Functions, recursion, variable scope, lambda expressions, and generators

### Artificial Intelligence and Search
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Greedy Best-First Search
- A* Search
- Hill Climbing

### Data Handling and Visualization
- NumPy array creation and manipulation
- Array arithmetic, reshaping, sorting, and aggregation
- Pandas DataFrames and MultiIndex
- Matplotlib line, pie, violin, scatter, histogram, bar, quiver, meshgrid, contour, and area plots

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/learner-Piyush/AI_Lab_Sem_5.git
cd AI_Lab_Sem_5
```

### 2. Create a Python environment (recommended)

Using Conda:

```bash
conda create -n ai-lab python=3.12
conda activate ai-lab
```

Or use an existing Python 3 environment.

### 3. Install the required packages

```bash
python -m pip install numpy pandas matplotlib notebook ipykernel
```

Most search-algorithm exercises use Python's standard library and do not require additional packages.

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required `AssignmentN.ipynb` file and run its cells.

## Running the Notebooks

1. Open the repository in Jupyter Notebook or JupyterLab.
2. Select the appropriate Python kernel.
3. Open an assignment notebook.
4. Execute the cells in order using **Run All** or **Shift + Enter**.
5. For plots, ensure that Matplotlib is installed and that the notebook output is enabled.

Each assignment notebook can be opened and executed independently.
